# 刮削逻辑重构计划

## 修复清单

### #1 Comic/Ebook 添加防重试机制

**Comic 模块**

- `Comic.java`: 添加 `scrapeAttemptedAt` 字段（`LocalDateTime`）
- `ComicRepository.java`: 新增查询方法 `findUnscrapedAfterCutoff(LocalDateTime cutoff)`，替代 `findByMetadataSourceIdIsNullOrderByVolumeAsc()`
- `MangaScrapeService.java`:
  - `autoScrapeAll()`: 改用 `findUnscrapedAfterCutoff(now - 7 days)`
  - `autoScrapeComic()`: 当 `pickBestMatch` 返回 null（无自信匹配）时，设置 `scrapeAttemptedAt = now`
  - 添加 `markScrapeAttempted(Comic comic)` 私有方法

**Ebook 模块**

- `Ebook.java`: 添加 `scrapeAttemptedAt` 字段（`LocalDateTime`）
- `EbookRepository.java`: 新增查询方法 `findUnscrapedAfterCutoff(LocalDateTime cutoff)` — 条件：`bangumiId IS NULL AND openLibraryId IS NULL AND (scrapeAttemptedAt IS NULL OR scrapeAttemptedAt < :cutoff)`
- `EbookMetadataScrapeService.java`:
  - `autoScrapeAll()`: 改用 `findUnscrapedAfterCutoff(now - 7 days)`，替换当前的 `findAll().stream().filter(...)`
  - `autoScrapeEbook()`: 当 Bangumi 和 Open Library 都无自信匹配时，设置 `scrapeAttemptedAt = now`
  - 添加 `markScrapeAttempted(Ebook ebook)` 私有方法

### #2 Comic/Ebook 异步化刮削

**Ebook 模块** — `EbookMetadataScrapeService.java`

- 使用 `Executors.newVirtualThreadPerTaskExecutor()` 提交每个电子书的刮削任务
- 移除 `Thread.sleep(500)`

### #3 Video 扫描阶段重复刮削

**文件**: `VideoService.java`

- **移除** `extractAndSaveMetadata()` 中的异步 `tryScrapeVideo` 调用（第 404-406 行）
- **移除** `extractAndSaveMetadata()` 更新已有记录路径时的异步 `tryScrapeVideo` 调用（第 348-350 行）
- 理由：`autoScrapeAll()` 已经覆盖了所有未绑定的视频，扫描阶段的异步刮削与 `autoScrapeAll` 存在竞争条件（视频可能被两个路径同时刮削）。统一由 `autoScrapeAll` 处理更清晰。

### #4 Music periodicScan 不应在 writeLock 内刮削

**文件**: `MediaWatcherService.java`

- 将刮削循环（`needsScraping` + `scrapeTrack`）从 `periodicScan()` 中移出
- `periodicScan()` 只执行 `scanDirectory`（索引文件）
- 刮削部分改为在 `periodicScan` 结束后异步执行，或者在 `scanDirectory` 完成后通过 `scrapeExecutor` 提交

具体改法：
```java
private void periodicScan() {
    List<String> rootPaths = getRootPaths();
    if (rootPaths.isEmpty()) return;
    for (String rootPath : rootPaths) {
        metadataService.scanDirectory(rootPath);
    }
    // 刮削移到异步执行，不阻塞 writeLock
    scrapeExecutor.submit(this::scrapeUnscrapedTracks);
}

private void scrapeUnscrapedTracks() {
    var tracks = metadataService.getAllTracks();
    for (var track : tracks) {
        if (scrapeService.needsScraping(track)) {
            scrapeService.scrapeTrack(track);
        }
    }
}
```

- 在 `MediaWatcherService` 中添加 `private final ExecutorService scrapeExecutor = Executors.newVirtualThreadPerTaskExecutor();`

### #5 Music 添加手动刮削封面端点

**文件**: `MusicController.java`

- 添加 `POST /{id}/cover/scrape` 端点
- 调用 `MusicScrapeService.scrapeTrack(trackId)` 触发封面下载
- 返回更新后的曲目信息

```java
@PostMapping("/{id:\\d+}/cover/scrape")
@Operation(summary = "刮削封面", description = "从在线源获取专辑封面并保存到本地")
public ResponseEntity<ApiResponse<MusicTrack>> scrapeCover(
        @Parameter(description = "曲目ID") @PathVariable Long id) {
    MusicTrack track = service.scrapeTrack(id);
    return ResponseEntity.ok(ApiResponse.success(track));
}
```

注意：`MusicMetadataService` 需要暴露一个 `scrapeTrack` 方法，或者 `MusicController` 直接注入 `MusicScrapeService`。

### #7 Video TMDB 搜索添加匹配验证

**文件**: `VideoService.java`

- 在 `searchFromTmdb()` 返回结果后，`autoScrapeAll` 和 `tryScrapeVideo` 中取第一个结果前，添加相似度检查
- 参考 Comic 的 `pickBestMatch` 逻辑：精确匹配优先 → 相似度 >= 0.6

具体改法：在 `tryScrapeVideo` 和 `autoScrapeAll` 中，不再直接 `results.get(0)`，而是调用新增的 `pickBestTmdbMatch(results, query)` 方法：

```java
private TmdbSearchResult.TmdbSearchItem pickBestTmdbMatch(
        List<TmdbSearchResult.TmdbSearchItem> results, String query) {
    String cleanedQuery = cleanTitleForSearch(query);
    
    // 1. 精确匹配标题
    for (var r : results) {
        String name = r.getTitle();
        if (name != null && (name.equals(cleanedQuery) || name.equals(query))) {
            return r;
        }
    }
    
    // 2. 相似度 >= 0.6
    double bestScore = 0;
    TmdbSearchResult.TmdbSearchItem best = null;
    for (var r : results) {
        String name = r.getTitle();
        if (name == null) continue;
        double score = TitleCleaner.calculateSimilarity(cleanedQuery, name);
        if (score > bestScore) {
            bestScore = score;
            best = r;
        }
    }
    
    if (best != null && bestScore >= 0.6) {
        return best;
    }
    return null;
}
```
